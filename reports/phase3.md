# 第三阶段测试记录

开发分支：`feature/v0.3-zh-local-ai`。第三阶段实现默认未确认、人工确认与纠正、逐次识别历史、单条删除与清空，并保留旧收藏。

## 已运行

- `npm test`：18 项通过。覆盖记录结构与重载、默认未确认、确认和纠正、“都不是／无法确定”、删除、旧收藏、取消与失败重试、存储不可用及容量不足。
- `npm run test:browser`：本机无头 Chrome 的 17 项界面检查通过。使用可控 Worker 测试交互；刷新后记录可读取，取消和失败不会产生记录，清空后旧收藏仍在。记录见 `phase3-browser.json`。
- 真实 CLIP 单图集成：已许可的圣乔治缩略图在本机 Chrome 中完成推理，界面显示“身份尚未确认”，前三候选为圣乔治、圣路加、圣玛窦。该次模型初始化 5,909 毫秒、推理 1,433 毫秒。取消重试与阻断下载后的手动检索也通过。记录见 `phase3-integration.json`。
- 上述浏览器交互测试只观察到同源 GET 请求；本地历史的存储数据不含照片文件名或图像数据。代码不发送照片或历史数据。

## 仍待验证

- CLIP 在第二阶段七图小样本中仍有明显误判，尤其非圣人图也会被排出候选。当前“无法确定”是用户主动选择，不是模型自动拒判；未设相似度阈值。
- 未测 iPhone Safari、Android Chrome 实机内存和相机行为；未测真实 GitHub Pages、PWA 安装及断网重启后的模型缓存。这些属于第四阶段。
- 历史使用浏览器本地存储，可能被用户或浏览器清除。存储不可用或满额时只保留当前页面内的临时记录并显示警告。
